# 🍪 Pastry Recipe Webpages (HTML5 / CSS3)

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)](https://developer.mozilla.org/fr/docs/Web/HTML)
[![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)](https://developer.mozilla.org/fr/docs/Web/CSS)

A pair of responsive pastry recipe web pages created with pure HTML5 and CSS3 (featuring Google Fonts and FontAwesome icons). 

> **Personal Note:** I developed this project entirely self-taught during the 2020 lockdowns as a way to dive into coding and web development. It served as a hands-on exploration of web design fundamentals without relying on external JS frameworks.

---

## ✨ Features & Highlights

* **Pure CSS Gingham Background:** Layered linear-gradient creating a checkered tablecloth pattern.
* **Interactive Checklists:** Pure CSS custom checkboxes with strike-through feedback on clicked ingredients.
* **Responsive Layout:** Responsive CSS Grid & Flexbox structures adjusting across desktop, tablet, and smartphone screens.
* **Aesthetic Design:** Warm pink palette, custom typography (*Playfair Display* & *Poppins*), and embedded media cards.

## 🚀 How to Run

1. **Clone the repository:**
   ```bash

   cd pastry-recipe-webpages
   ```
2. **Open locally:** Double-click `index.html` or open it in your browser of choice.
